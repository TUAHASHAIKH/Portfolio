# Portfolio project selection

Reviewed the owner's public repositories through the connected GitHub account on 2026-10-29. Selection is based on documentation, repository structure, and representative source files, rather than executing the projects or claiming production readiness. Existing featured projects are retained. Pulse is first at the owner's request.

## Retained projects

AutoML, SecurePassFS, StraySense, Smart Ride, the 2048 AI agent, and NUSTFRUTA retain their source links. Descriptions and illustrations were refreshed using their README files; Smart Ride uses `RideApp.cpp` because that repository has no README. AutoML retains its existing live-demo link. Temporary tunnel URLs are not presented as permanent live demos.

## Image treatment

Every selected project has its own generated conceptual cover. The visual metaphor represents documented functionality without inventing application screens, performance figures, customers, or endorsements. Artwork uses the same 16:10 frame and centered composition. The 2048 board was corrected to four rows and four columns during review.

Public profile repositories, test fixtures, and personal/private repositories are excluded from this public showcase. Other public work was left out to keep the selection focused; omission is not a judgment of ownership or quality.

See [project-artwork.json](project-artwork.json) for the complete prompts, output filenames, and repository links.
